# Technology Stack

## Styling

Tailwind CSS

## Animation

GSAP

ScrollTrigger

## Package Manager

npm

## Images

Always use next/image unless there is a strong technical reason not to.

## Routing

Next.js App Router

Use dynamic routes where appropriate.

Prefer Server Components.

Use Client Components only when required.

## State Management

React Context

React Hooks

Avoid unnecessary global state.

## Backend

Next.js API Routes

Serverless architecture.

## Database

Currently no database.

Future integrations may include:

- Airtable
- Supabase
- PostgreSQL
- n8n
- Webhooks

## Deployment

Vercel

## Architecture Principles

Component-first architecture.

Reusable UI.

Server Components by default.

Client Components only when interaction is required.

Avoid duplicated logic.

Prefer composition over large components.

## Performance Principles

Lazy load expensive components.

Optimize bundle size.

Reduce JavaScript.

Use dynamic imports for heavy features.

Keep Lighthouse scores high.

Always optimize for mobile.

## SEO Principles

Every page should include:

- Metadata
- Open Graph
- Canonical URL
- Structured Data when appropriate

Never ship pages with missing metadata.
