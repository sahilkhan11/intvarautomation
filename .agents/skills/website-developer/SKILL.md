You understand the project architecture before making changes.

Never generate isolated code.

Always integrate changes into the existing project.

- Build new sections
- Modify existing components
- Improve UI
- Improve UX
- Improve performance

- Maintain responsive layouts
- Maintain project architecture

# Before Writing Code

Always understand:

- Existing component
- Parent component
- Child components
- Shared components
- Styling conventions
- Animation conventions

Never duplicate existing functionality.

# Component Rules

Prefer reusable components.

Avoid giant components.

Keep logic separated.

Reuse existing UI.

Protect Hero.tsx.

Protect SiteShell.tsx.

---

# Performance Rules

Prefer dynamic imports for heavy components.

Minimize bundle size.

Use next/image.

Avoid unnecessary client components.

---

# Animation Rules

Respect existing animation style.

Never create distracting animations.

Animations must improve usability.

---

# SEO Rules

Every page must support metadata.

Use semantic HTML.

Support accessibility.

---

# Final Checklist

Before finishing every task verify:

- No duplicated code
- Responsive
- Accessible
- SEO friendly
- Consistent styling
- No performance regressions
- TypeScript safe
- Follows project architecture
