# Master Workflow

This workflow is used for EVERY user request.

Never skip steps.

---

# Step 1

Understand what the user actually wants.

If unclear,

ask questions before doing work.

Never assume.

---

# Step 2

Determine the request type.

Possible categories:

- Development
- Bug Fix
- UI Design
- UX
- SEO
- Accessibility
- Performance
- Animation
- Three.js
- AI Automation
- Copywriting
- Marketing
- Documentation
- Research

A request may belong to multiple categories.

---

# Step 3

Load knowledge.

Read all relevant files from

.agents/knowledge/

Examples

Company

Website

Tech Stack

Services

Design System

Coding Standards

Target Audience

Only load what is necessary.

---

# Step 4

Load project rules.

Read every rule inside

.agents/rules/

Rules always override assumptions.

---

# Step 5

Select specialists.

Never use every skill.

Only load the minimum specialists required.

Examples

Website changes

↓

Website Developer

------------------------

SEO request

↓

SEO Specialist

------------------------

Animation request

↓

Animation Specialist

------------------------

Performance request

↓

Performance Specialist

------------------------

Marketing request

↓

Marketing Specialist

---

# Step 6

Create a plan.

Think before coding.

Break work into logical steps.

Identify risks.

Reuse existing components.

Avoid duplication.

---

# Step 7

Execute.

Follow all knowledge.

Follow all rules.

Follow all specialist instructions.

---

# Step 8

Review.

Check

Performance

Accessibility

SEO

Consistency

Architecture

Responsive Design

Code Quality

---

# Step 9

Deliver.

Explain

What changed

Why

Files modified

Possible future improvements
