# Skill Installer

Convert any Claude Skill (.md) into an Intvar AI Skill.

The workflow should NEVER simply copy the original file.

Instead it must perform the following steps.

----------------------------------

# STEP 1

Read the original skill.

Understand:

Role

Purpose

Workflow

Inputs

Outputs

Rules

Examples

Quality checks

Dependencies

----------------------------------

# STEP 2

Analyze the skill.

Determine:

Which department owns this skill.

Possible departments:

Development

SEO

Marketing

Sales

Automation

Analytics

Performance

Documentation

Design

Research

Project Management

If no department exists,

recommend creating one.

----------------------------------

# STEP 3

Read project knowledge.

Read

.agents/knowledge/

Only load relevant files.

----------------------------------

# STEP 4

Read

.agents/rules/

----------------------------------

# STEP 5

Rewrite the Claude Skill.

Transform it into an Intvar-native skill.

The rewritten skill must:

Understand Intvar.

Understand the website.

Understand the coding standards.

Understand project architecture.

Never duplicate project rules.

Reference project knowledge instead.

----------------------------------

# STEP 6

Generate metadata.

Skill name

Description

Department

Dependencies

Required knowledge

Related workflows

Related agents

Suggested triggers

----------------------------------

# STEP 7

Run quality review.

Check:

No duplicated rules.

No conflicting instructions.

No generic wording.

No missing dependencies.

Consistent formatting.

----------------------------------

# STEP 8

Recommend:

Should this become

A Skill

A Workflow

A Rule

Shared Knowledge

Utility Script

or Specialist Agent?

Explain why.

----------------------------------

# STEP 9

Output

The final production-ready Intvar Skill.

Also generate a migration report explaining:

What changed.

What was removed.

What was merged.

What project knowledge is used.

Which department owns it.

Never modify the original Claude skill.
