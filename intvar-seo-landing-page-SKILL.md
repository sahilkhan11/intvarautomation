# Intvar SEO Landing Page Builder

## When to use
- Creating a new service page (e.g. /mobile-app-development-rajasthan/) or city page (e.g. /mobile-app-development-jodhpur/)
- Rewriting a title tag / meta description for a page that has impressions but 0 clicks in Search Console
- Adding a "proof" section to an existing thin page

## Non-negotiable rules
1. Stay inside Sahil's 21-page budget. Before creating a new page, check whether an existing page should be edited instead of adding one.
2. One new page per session — matches Sahil's phased, one-prompt-per-session build discipline. Never batch multiple new pages in one go.
3. Never create near-duplicate pages that only swap a city name. Each page needs its own intro copy, its own proof section, and a distinct primary-keyword angle.
4. Title tag format: "{Primary Service} in {Location} | Intvar" — never generic ("Home | Intvar"), never keyword-stuffed (no "Best X Best Y" repeats).
5. Every service/location page must include, in this order:
   1. H1 matching the page's search intent
   2. 2-3 sentence value section
   3. "Services covered" block (bulleted sub-services)
   4. Proof section — real projects, industries served, tech stack. Ask Sahil for the actual details; never invent client names or case studies.
   5. FAQ block seeded from real Search Console queries Sahil provides for that page
   6. Internal-links block: up to the parent hub page, sideways to sibling service/city pages
6. Internal link anchor text must be descriptive ("Android app development in Jodhpur"), never "click here."

## Page hierarchy to respect
```
Intvar → Mobile App Development → Rajasthan → {Jodhpur | Alwar | Jaipur | ...}
Intvar → Software/Web Development → Rajasthan → {Alwar | ...}
```

## Steps
1. Ask which page in the hierarchy this session targets: a service hub page, or one specific city page.
2. Use the real Search Console queries Sahil provides for that page to shape the H1, FAQ block, and meta description. Don't invent queries or stats.
3. Draft the title + meta description first and confirm with Sahil before writing full page copy.
4. Write the page section-by-section in the required order above.
5. Add the internal-link block last, linking to the correct parent/sibling pages per the hierarchy.
6. Flag it if this page would push the site over the 21-page budget, and suggest which existing page to fold it into instead.
